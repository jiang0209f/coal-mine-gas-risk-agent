# 瓦斯风险工作台前端

使用 Vue 3、ECharts 和 Vite，所有运行资源打包到本地，接口前缀为 `/api`。

```powershell
npm ci
npm run check
```

`npm test` 检查接口鉴权、文件上传、错误消息与时间边界；`npm run build` 编译页面并核对本地资源；`npm run test:e2e` 使用隔离接口夹具在无头 Edge/Chrome 中验证三个角色、会话推进、事件依据、建议审核、执行反馈、对话及模型状态。E2E 不调用真实模型。可用 `UI_TEST_BROWSER` 指定 Chromium 系浏览器路径。

开发时运行 `npm run dev`，访问 `http://127.0.0.1:5173`，接口代理到 `http://127.0.0.1:8000`。部署由 FastAPI 挂载 `frontend/dist`。

账户由后端初始化命令配置，页面不创建默认账号。登录后选择数据源和监测点，创建或恢复会话；所有时间输入和显示均使用矿区时间 UTC+8。暂停时停止自动推进，继续时每 5 秒请求一次服务端 tick；历史模式的“前进 60 秒”传入明确的数据时点，现场模式刷新服务端当前时间。曲线查询截止当前会话 `as_of`，缺测保持为空。

对话提交异步任务并轮询实际任务状态，进行中任务可取消。

安全管理人员可上传数据、登记和审核条文；已批准的实际引用可用于建议草拟。建议版本审核、执行、反馈和复核均提交后端校验。页面只显示后端返回的数据、模型状态和评估报告。
