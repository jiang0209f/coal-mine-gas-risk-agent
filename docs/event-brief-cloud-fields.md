# DeepSeek简报拟外发字段

日期：2026-11-03。用途：确认31002真实历史来源的自动研判简报外发范围。

## 目的地和来源

- 目的地：DeepSeek官方聊天接口 `https://api.deepseek.com/chat/completions`。
- 模型：当前配置的 `deepseek-flash`。
- 拟授权来源：`multisensor-31002-2022`，即31002工作面2022年1—2月多源历史数据。
- 用途：新预警或等级升级后，生成带出处的事件研判简报；人工生成或重试采用相同范围。
- 当前状态：真实来源外发允许名单为空。模型前先检查来源授权，未授权时只保留本地工具结果。

## 拟发送内容

字段来自服务端冻结事件和实际工具返回。下表为代码中的传输范围，尚未向DeepSeek发送真实矿井数据。

| 类别 | 字段与数量范围 |
| --- | --- |
| 事件事实 | 事件编号、修订、测点编号、类型、等级、开始/结束时间、修订截止时间、规则版本及质量标志 |
| 规则 | 规则版本、草案/正式状态、单位、实测红色/橙色阈值和橙色持续时间 |
| 观测摘要 | 有效记录数量、最小/最大值、峰值时间；按时间选取首末观测，最多12条，每条含时间、数值、质量标志 |
| 候选溯源 | 运行状态、模型编号与版本、目标时间、输入截止、候选工况名称及概率语义；分类概率和完整六通道输入保存在本地 |
| 已有预测 | 运行编号、模型版本、状态、起算时间；最多3组物理预测或决策输出，每组最多12个区间的起止时间、预测值、输出语义和单位 |
| 已审核资料 | 按需检索最多8段，每段最多1000字符，含引用编号、资料编号与版本、来源和页段定位 |
| 处置进展 | 处置阶段、演练/现场性质、待办事项和动作数量，不包含人员身份及操作正文 |
| 引用定位 | 至多24个服务端引用编号，及对应事件修订、模型运行号、观测编号、文件摘要标识、原始行号、时间或资料版本/页段 |

发送前处理本机路径和密钥样式文本。模型只接收上述事实和有边界的工具摘要；权重、源文件、完整原始时序、366条或2700条模型输入引用、私有配置和人员操作正文保存在本地。API Key仅用于服务端接口鉴权，不作为简报字段，不进入模型消息、报告或GitHub。

## 确认后的执行范围

确认后，仅将上述来源加入私有配置 `EVENT_BRIEF_ALLOWED_SOURCE_IDS`，其他真实来源保持关闭。简报触发、模型调用数量、使用量、工具步骤和引用均保存到F盘运行记录。

每个新事件或等级升级自动提交一次；普通修订和重复推进复用已有任务。失败重试、取消与生成当前版本均由页面显式操作。

如果希望缩小观测、预测或资料片段的范围，可以先指定删减项，再更新传输字段与测试。
