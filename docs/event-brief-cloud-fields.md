# 数据使用规则：真实来源本机处理，云端仅使用纯合成数据

日期：2026-11-04。本文记录当前确定的数据使用规则，原文件名保留以兼容已有链接。

## 当前规则

| 数据范围 | 处理位置与行为 |
| --- | --- |
| 真实监测、预测、溯源、规程和处置资料 | 在本机存储、计算和展示；普通对话使用本地结构化模板，主动简报保留本地事件依据 |
| 纯合成隔离数据 | 在独立数据库中构造合成事件、观测、预测、资料及处置记录，用于DeepSeek工具调用和简报展示 |
| 生产运行库 | `EVENT_BRIEF_ALLOWED_SOURCE_IDS=[]`，普通 `/chat` 与主动简报共同执行来源门禁 |

普通对话对未允许来源返回 `structured_template`，并记录 `local_reason=cloud_source_not_authorized`。主动简报读取本地依据后返回 `cloud_source_not_authorized`，保留工具步骤、结果卡和引用。系统尚未部署本地大模型，真实来源的这些结果属于规则、预测、溯源和工具查询结果。

`EVENT_BRIEF_ALLOWED_SOURCE_IDS` 的名称为兼容保留，当前同时约束普通对话和主动简报。允许名单只用于经核验的纯合成隔离来源，生产保持空列表。真实来源不加入此名单。

## 合成云端验证

云端验证使用独立数据库，观测、事件、预测、知识资料和处置记录全部由合成流程创建。合成会话不连接生产库，也不检索真实矿井规程或真实处置记录。

数据源改名、替换测点编号、使用 `simulated_stream` 模式或添加“合成”标签，都不能改变真实数据的来源性质。回放真实历史数据仍按真实来源在本机处理。

DeepSeek接口为 `https://api.deepseek.com/chat/completions`，当前模型配置为 `deepseek-flash`。纯合成验证按现有简报字段投影发送有限的合成事实、工具摘要和引用编号，记录请求数、使用量及工具往返结果。API Key仅用于服务端鉴权，保持在私有配置中。

## 历史方案中的真实字段清单（未执行）

旧版方案曾列出 `multisensor-31002-2022` 的真实事件摘要及以下字段范围。该真实数据外发方案未执行，现已由“真实来源本机处理，云端仅使用纯合成隔离数据”的规则取代。本表仅保留历史方案索引。

| 类别 | 旧版列出的真实字段范围 |
| --- | --- |
| 事件事实 | 事件编号、修订、测点编号、类型、等级、开始/结束时间、修订截止时间、规则版本及质量标志 |
| 规则 | 规则版本、草案/正式状态、单位、实测阈值和持续时间 |
| 观测摘要 | 有效记录数量、最小/最大值、峰值时间；首末观测最多12条，每条含时间、数值和质量标志 |
| 候选溯源 | 运行状态、模型编号与版本、目标时间、输入截止、候选工况及概率语义 |
| 已有预测 | 运行编号、模型版本、状态、起算时间；最多3组输出，每组最多12个区间 |
| 已审核资料 | 最多8段，每段最多1000字符，含资料版本、来源及页段定位 |
| 处置进展 | 阶段、演练/现场性质、待办和动作数量 |
| 引用定位 | 至多24个引用编号及其事件修订、运行号、观测编号、文件标识、行号或资料页段 |

真实源文件、完整时序、模型输入引用、权重、规程、人员操作和真实任务记录继续保存在本机。合成云端验证和真实本地验收分别保存报告，源码与说明同步GitHub；数据及运行产物保存在F盘，私有配置保存在本地。
