# 综合态势页面 v0.3

本版供页面设计审核，交付可操作的本地网页、截图和布局检查脚本。正式 Vue 页面继续保留，审核后按此布局接入现有功能。

## 本次调整

v0.2 在 1920×1080、1440×900 下页面均高约 1091px；后一尺寸有约 191px 落在屏外。左右及中央区域底边不齐，部分辅助文字为 10px，地图标签随容器百分比定位。

v0.3 按浏览器可用高度分配整页空间，左侧测点与质量面板、中央工作面与曲线共用两条行轨道，右侧研判区跨两行。底部日志独立占一行。摘要卡、面板标题、日志表头与数据行均有明确高度。

- 工作面监测是中央主视图，浓度曲线保留独立读图空间。
- 智能研判整合为一个工作区，内部切换结论、依据和人工处置，操作按钮固定在底部。
- 取消重复的测点统计圆环，集中显示当前浓度、预警、待办、模型状态四项摘要。
- 保留深蓝底色，青色表示交互与常规趋势，红色表示报警，琥珀色表示待办与质量疑点。边框和背景采用低对比层次。
- 常规正文 14px，紧凑窗口正文 13px，辅助信息至少 12px；主指标 32px/28px。数值使用等宽数字排列。
- 地图卡片、指引线和巷道文字根据 SVG 坐标投影定位。

## 前端开发方法对比

| 方法 | 对当前页面的影响 | 本版处理 |
| --- | --- | --- |
| 固定 1920 画布并整体缩放 | 实现快；窗口缩小时字体、按钮随画面一起变小，不同宽高比可能出现空白或裁切 | 采用实际窗口布局，文字保持可读尺寸 |
| 每张卡独立设置高度和断点 | 局部易调，累计后易出现列底不齐、页面溢出、规则互相覆盖 | 由同一个 Grid 分配行列，共用尺寸变量 |
| CSS Grid 的 minmax/fr，加宽度和高度断点 | 能协调主次区域、适应不同窗口；需处理内容最小高度与内部滚动 | 采用此方案；面板设 min-height:0，长内容在面板内滚动 |
| 引入新的组件库或换框架 | 可统一控件，但页面比例仍需单独设计，并增加迁移成本 | 延续项目已有 Vue/ECharts；当前审核稿使用原生 HTML/CSS/JS |

布局和字级参考 [Ant Design 布局规范](https://ant.design/docs/spec/layout/) 与 [字体规范](https://ant.design/docs/spec/font/)。行业页面参考保留深蓝、主视图、专业曲线、事件表的表达，尺寸按本项目实际信息量重新分配。

## 尺寸验收

以下为浏览器实际 DOM 测量，面板宽高取整，单位 px。

| 窗口 | 左侧宽 | 中央宽 | 右侧宽 | 工作面高 | 曲线高 | 日志高 | 首屏完整日志行 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1920×1080 | 328 | 1136 | 384 | 340 | 278 | 170 | 3 |
| 1440×900 | 274 | 761 | 346 | 272 | 222 | 154 | 3 |
| 1366×768 | 260 | 727 | 328 | 223 | 183 | 126 | 2 |
| 1024×900 | 收入测点入口 | 670 | 304 | 272 | 222 | 154 | 3 |

四种桌面窗口均无整页横向或纵向溢出；左、中、右区域顶边和底边对齐。日志在区域内滚动。768px、390px 宽窗口改为纵向排列，无页面横向溢出；日志保留内部横向滚动。

`layout-check.mjs` 使用现有 Playwright 和本机 Edge 验证以下内容，并输出截图与 JSON：

1. 桌面页面边界、面板对齐、主视图和曲线最小高度。
2. 摘要卡高度及下方间距，日志末行完整显示。
3. 地图文字与测点卡片无重叠，辅助字号至少 12px。
4. 页面不出现用户要求删除的设计说明文字。
5. 测点切换、趋势/对比/预测状态、依据页签、人工确认、窄屏显示。
6. 浏览器无脚本运行错误。

## 审核稿的数据与交互范围

监测曲线、预警事件、阈值 0.80%、时间和处置内容采用固定设计数据；工作面、巷道、设备和测点几何位置用于布局审核。质量记录数量沿用导入验收统计，并按固定快照显示。正式接入时由后端返回实际监测、规则、质量与状态数据。

测点选择、图表切换、弹窗、依据查看和处置状态可在本地操作。提问和建议采用本地交互内容。专业预测显示“未就绪”，待已有模型适配与模型产物就绪后接入。此页面无 DeepSeek API 请求和密钥配置。

## 文件

- `index.html`：页面分区与业务文字。
- `styles.css`：色彩、尺寸、字号、共用栅格及响应式规则。
- `app.js`：设计交互、地图坐标投影、图表与弹窗。
- `mine.svg`：可缩放工作面图形。
- `layout-check.mjs`：布局与设计交互检查。

F 盘归档目录：`F:\煤矿瓦斯智能体\documents\design-review\v0.3`；`qa` 子目录包含桌面与窄屏截图、交互截图及布局报告。
