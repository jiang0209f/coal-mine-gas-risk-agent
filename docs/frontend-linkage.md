# 前端与真实监测、预测及溯源联动

日期：2026-11-03。对应[整体模块设计 v0.6](module-design-v0.6.md)第一阶段。

## 页面与操作

正式 Vue 工作台采用深蓝配色和响应式布局：顶部选择数据源、测点和会话，摘要显示监测值、事件、预测和溯源状态；左侧为测点与质量，中间为六通道读数和趋势，右侧为事件研判，底部为事件记录。当前资料中的测点没有空间坐标，中央按通道展示实际读数。

1. 登录后选择“31002多源历史数据（2022年1—2月）”。来源下方显示已存历史的时间范围、观测条数和测点数量。
2. 创建历史回放，或恢复已有会话。新会话的初始时间取自实际数据目录；历史时刻采用矿区 UTC+8，现场会话使用服务器时钟。
3. 选择 T0 瓦斯浓度和预测模型，点击“运行预测”。模型选择绑定编号及版本；基线保持默认，专业模型可显式选择。
4. 曲线同时显示实测与预测，横轴覆盖预测结束时间。“预测区间数据”可展开查看每段起止时间、数值、单位、模型版本及输入截止时间。
5. 点击实测事件，曲线切换到事件附近，右侧显示指定修订的候选原因、类别概率、目标时间、输入截止和输入引用数量。原始依据和人工处置使用同一事件；“打开人工处置”进入完整处置页面。
6. 切换到风速、电流等工况测点时显示对应读数和单位，停止甲烷预测、规则和事件请求。未知计量单位显示“原始单位”，质量面板记录“单位待核对”。

页面保留资料登记、审核、建议、人工处置、对话和评估入口。主动事件简报、文档文件上传及会话评估采集器继续按后续阶段实施。

## 联动与时间约束

| 对象 | 关联范围与行为 |
| --- | --- |
| 监测与通道卡 | 使用同一会话和 as_of，过滤未来观测、晚到值和未闭合聚合桶；缺测保持空值 |
| 预测 | 绑定 session_id、source_id、point_id、model_id 和 version；输入截止、输出区间与模型版本可查 |
| 会话恢复 | 从预测运行库读取所选模型的最新可见结果，恢复已有结果时不重新推理 |
| 事件 | 依据请求明确传递 event_revision；曲线显示事件前后范围，查询截止受会话时钟限制 |
| 溯源 | 适用实测事件由依据查询触发，读取六通道历史；同事件修订及模型配置复用已有运行 |
| 预测与事件 | 实测事件保留同上下文适用预测，预测事件采用其精确关联的预测运行 |
| 来源或测点切换 | 立即清空旧曲线、事件、预测及溯源；请求代次和上下文校验阻止旧响应回写 |

当前专业预测以五分钟区间输出，31002训练定义的目标为区间 T0 最大值；实测曲线采用分钟查询值。预测起算时间与会话分钟时刻可以相差不足五分钟，页面分别展示其时间。

质量统计对应当前查询窗口，历史目录统计对应来源内已存观测。六通道的“观测条数”与“分钟时刻数”分别计数。

## 新增与复用接口

| 接口 | 用途与返回 |
| --- | --- |
| `GET /api/sources/{source_id}/coverage` | 已授权来源的历史目录。返回 semantics=stored_history_catalog、有效值口径、总/有效条数、各测点元数据与 start_at/end_at；end_at 包含最后一个有效时刻 |
| `GET /api/forecasts?session_id=...&point_id=...&model_id=...&version=...&limit=1` | 按会话、来源、测点、模型版本和 as_of 筛选已保存预测，最新优先。limit 为1–100 |
| `POST /api/forecasts` | 原预测接口新增可选 version，按选定版本运行；其余调用方式保持兼容 |
| `GET /api/observations`、`GET /api/events` | 监测曲线、通道读数及事件列表，复用会话时间约束 |
| `GET /api/evidence?...&event_revision=...` | 读取指定事件修订的观测、规则、预测与 candidate_attribution |
| `GET /api/cases/{event_id}` | 读取同一事件的人工阶段、建议审核及操作记录 |

历史目录用于回放时间选择；会话内监测查询仍同时检查 event_time、available_at 和 as_of。目录接口不输出本机文件路径。

## 实现位置

- `frontend/src/App.vue`：会话、模型、预测、事件和依据的请求编排与状态切换。
- `frontend/src/workspace.mjs`：上下文匹配、请求代次、模型选择、可见读数与事件窗口计算。
- `frontend/src/components/MonitorWorkspace.vue`：深蓝主工作区、ECharts实测/预测曲线、通道卡及事件研判。
- `frontend/src/style.css`：导航、公共控件和响应式样式。
- 后端 data 与 prediction 服务：历史目录和已保存预测查询；继续使用既有服务分层。

## 验收

先建立失败测试，再实现查询及前端联动。后端643项通过、5项跳过；前端15项单元测试、5项界面测试及生产构建通过。界面夹具覆盖三个角色、指定模型版本、12区间展示、重复查询、人工处置、未来值过滤，以及溯源请求未返回时切换测点。

真实数据浏览器验收使用 F 盘隔离运行库：从生产库只读抽取31002六通道及同区间原始T0，共5682条观测，保留原行编号和来源引用。临时验收账户与生产账户分开，验收后清理；模型使用现有 F 盘权重。

真实链路核对：基线恢复、专业预测的2700条输入引用及12个区间逐值显示、实测橙色事件及指定修订、溯源366条输入引用和重复复用、工况测点隔离、跨来源清空和恢复。1920、1440、1280及390px窗口检查整页横向溢出和操作可达性。

生产数据源条数、抽取观测切片摘要及训练产物哈希前后核对。浏览器验收禁用外部请求，未调用DeepSeek。测试跳过项涉及独立模型依赖、需指定原源码路径的原生模型测试及F盘符号链接；本轮专业预测与SVC已另用真实权重验证。
