## 专业模型封装验收（训练前记录）

FEDformer＋12阶段LightGBM预测封装、六通道KMeans/SVC候选溯源封装、独立JSON进程及三条认证HTTP接口已完成。输入为训练顺序的预加工特征，运行记录标记为submitted_features，受来源、工作面、会话与时钟限制。原始监测特征加工与常规预测工具衔接按后续步骤实施。

F盘后端完整回归555项通过，3项跳过；模型独立环境的82项验收全部通过，包含真实FEDformer随机权重与小型LightGBM产物、合成SVC的保存/加载/推理和独立进程往返。两组测试部分重叠，数量分别记录。跳过项为后端环境未安装的两项模型依赖测试及F盘不支持的符号链接测试；两项模型测试已在独立环境通过。

封装修正了权重未加载就报告就绪、窗口参数过宽、版本身份不一致、物理残差与阈值偏移混用，以及LightGBM中文路径加载问题。原溯源统计轴保持legacy_row_stats_v1，绝对值处理由产物清单显式声明。

生产登记模板缺训练权重，当前状态均为not_ready。验收验证封装与运行条件，真实预测误差及成因溯源效果待训练产物和独立数据验证。使用方式见[模型封装说明](model-packaging.md)，本地验收记录位于F盘outputs/model-packaging。

## 首轮训练及聚类验算

31002六通道加工历史源已导入302,880条观测，原始T0源770,930条保留。FEDformer及12阶段LightGBM、KMeans/SVC均已真实训练并生成权重，存放F盘models/trained；本次专业预测输入特征从运行库自动构造，已衔接常规预测接口和智能体工具，服务输出与离线封装样例完全一致。

二月独立测试中，持久性、FEDformer、残差修正MAE分别为0.046265、0.067051、0.089148，一月验证也以持久性较低，因此默认保留基线，专业模型显式调用。旧SVC二月聚类类别准确率14.40%，聚类标签2718条手算均一致，但聚类数/原因映射依据不足，且未缩放的统计特征导致核值退化。该轮验算结束时自动溯源关闭；其后按用户要求启用，当前状态见下节。

详细分区、权重、原因映射及核距离验算见[训练与聚类验算](training-and-clustering-audit-20261103.md)。F盘clustering-audit包含独立脚本、逐例距离和完整数据；这些原值与权重未上传GitHub。

最终后端回归611项通过、5项跳过；模型环境训练/接入测试48项通过。跳过项涉及独立模型依赖与F盘符号链接，真实训练权重的独立进程及运行库接入已另行验收。智能体上下文补入当前来源可用的模型和测点编号，保留实验/默认标记并过滤私有路径；本轮未发送真实监测数据到DeepSeek。
