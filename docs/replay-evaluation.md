# 回放记录采集与冻结评估

日期：2026-11-04。会话记录采集、冻结报告、指标明细及原始观测回查在本机完成，真实数据不进入DeepSeek。代码和使用说明同步GitHub；环境、运行库、导出及验收产物保存在F盘。登录页面沿用现状。

## 从会话生成报告

安全管理角色选择会话、分析区间、甲烷测点和一个模型版本，调用`POST /api/evaluations/from-session`。采集器只读取已保存记录，不推进会话时钟、不重新运行预测或预警判断。

```json
{
  "session_id": "已有会话编号",
  "start_at": "2022-02-05T20:00:00+08:00",
  "end_at": "2022-02-05T20:20:00+08:00",
  "point_ids": ["当前来源的甲烷测点编号"],
  "model_id": "已登记模型编号",
  "model_version": "已保存运行的模型版本",
  "prediction_stage": "residual_corrected",
  "dataset_split": "unclassified",
  "tolerance_seconds": 0
}
```

区间须位于会话起始时间之后，结束不晚于会话数据时钟。`end_at`是冻结数据截止，观测可用时间、事件修订、任务及操作的数据时间均受其约束。已有多个模型或版本时必须明确选择，物理预测与决策分值分别处理。未指定预测阶段时优先选择`residual_corrected`，否则使用唯一的物理预测阶段。

`dataset_split`可选`unclassified/train/validation/test`，默认`unclassified`，清单记录`dataset_split_semantics=user_declared`。分区标签由使用者声明，系统不会据此认定数据已经完成独立测试划分。

## 会话审计与关联重放

创建、暂停、继续、变速、推进和停止会话均追加`session_action`记录。每条记录包含动作编号、会话、来源、工作面、顺序号、身份、`occurred_at`和`data_as_of`，以及动作前后的时钟、状态和倍速。旧会话缺少的历史审计不补造。

页面支持回放倍速与“从此处新建回放”。重新回放创建带`parent_session_id`的新会话，原会话及已冻结报告继续保存。新旧会话各自维护单调时钟；在相同数据、模型和规则下按同样步骤推进，可比较指标值及分子分母，报告编号、操作时间和审计身份分别保留。

采集内容包括会话快照、会话动作、最小推进记录、可见事件修订、已保存预测、监测观测、任务元数据、建议引用及人工动作。对话消息、建议正文和人工操作正文不进入评估采集结果。

## 实测、预测与时间口径

实测事件来自会话已保存的`observed_exceedance`修订，标记为`saved_session_observed_threshold_events`和`observed_threshold_derived`。这些记录表示冻结规则识别的实测阈值事件，事故标签和成因标签另行采集。没有实测事件且没有已完成实测评估记录时，事件指标标明`observed_event_evaluation`缺项。

预测事件只使用实际保存的`forecast_exceedance`通知及其关联模型运行。采集器将通知映射到所选物理预测阶段中、达到冻结预警阈值的成熟目标区间，合并同一通知内连续或重叠的目标片段。`issued_at/notification_start_at/notification_end_at`记录通知时间，`target_start_at/target_end_at`或目标事件`start_at/end_at`记录预测所指时段。

预测目标窗口采用`[start_at,end_at)`。提前发出的通知不因发出时间位于分析窗口之外而丢失；尚未成熟或缺少完整实测支持的目标区间不进入主匹配。事件在分析左端已经恢复正常时不纳入该窗口；开放事件的左端观测和原始瞬时超限点保留。

样本单位是一个已保存运行、一个物理预测阶段和一个目标区间。实际值按声明的`interval_mean`或`interval_maximum`等目标统计量计算，清单与样本记录实际使用的均值或最大值。基线可使用其声明的`input_statistic`；专业模型未声明目标统计量时记录缺项，不推定为均值。每个样本保留预测值、实际值、阈值、模型版本、目标时间和原始观测引用。

目标区间内的观测用于计算实际值，区间端点及必要的前一观测用于核验连续支持。边界支持记录单独标记，不作为区间内额外样本。观测事件时间与可用时间均须满足冻结截止。人工动作另记录实际操作时间，监测数据时间、操作时间及建议已有的资料核验时间分别保留。

## 有效时长与疑似标校

有效监测时长累计相邻有效观测之间、不超过冻结规则最大间隔的支持区间。无效值、缺测和超过间隔的断档不补满，末条观测之后不外推时长。

多个测点的时长按测点相加，单位为`sensor-hours`，并给出逐测点明细。每有效监测小时误报数的分母采用该口径，与墙钟经过时间分别说明。

主视图`primary/all_events`保留有效观测中的疑似标校记录；`excluding_suspected`重新剔除带`suspected_calibration`标志的事件、样本、观测及支持区间，再计算匹配和对应分母。没有剔除后的有效时长时标记缺项，不沿用主视图分母。

## 指标及明细

| 指标 | 计算与回查内容 |
| --- | --- |
| 逐事件查准率、召回率 | 预测目标窗口与实测阈值事件一对一匹配；保留匹配对和未匹配事件 |
| 漏报事件数 | 有事件评估条件时，统计未匹配的实测阈值事件 |
| 每有效监测小时误报数 | 未匹配目标事件数 / 有效测点支持小时数；分母可回查到支持区间及两端观测 |
| 逐样本查准率、召回率、FPR | 按冻结样本阈值得到TP/FP/TN/FN，FPR分母为实际负样本数 |
| MAE、MAPE | 逐样本绝对误差；MAPE排除实际值为零的样本并保留该策略和分母 |
| 工具任务完成率、依据完整率 | 实际任务状态和证据记录，排队任务保留原状态并按运行中归一化 |
| 建议出处覆盖率 | 按独立建议条数及有出处条数计算，手工建议不伪造工具任务，不与任务内建议重复计数 |

没有已保存预测、没有成熟样本、预测阶段不支持现有预警策略、尚未完成实测评估或分母为零时，报告返回不可计算状态及具体原因。零正例、零负例和零有效时长分别展示；缺项不填成0或100%。

明细保留每条记录的纳入状态、分子贡献、分母贡献及冻结事实。原始观测回查读取冻结清单中的原始值、有效值、质量、文件编号、行号及两种时间，不重新查询活数据。

## 冻结完整性与本地导出

`records_sha256`校验冻结记录，`manifest_sha256`校验清单，`report_sha256`校验报告。读取报告、指标明细和原始观测时校验关联内容；已有冻结清单构建报告会复用已保存报告。活预测、事件或观测后续变化不改写原报告。

HTTP清单和JSON导出采用脱敏投影，移除私有消息字段、原文正文、路径字段，并处理路径及密钥样式文本。导出保留原始冻结摘要用于关联，同时额外计算`export_records_sha256`和`export_manifest_sha256`，分别对应实际导出的记录和清单。脱敏后的字节内容与本地原始冻结内容分别校验，不把原始摘要冒称为导出投影摘要。

| 接口 | 用途 |
| --- | --- |
| `GET /api/evaluations` | 查询授权工作面的已冻结报告 |
| `POST /api/evaluations/from-session` | 从实际会话只读采集并冻结报告 |
| `GET /api/evaluations/{evaluation_id}` | 查询并校验冻结报告 |
| `GET /api/evaluations/{evaluation_id}/manifest` | 查询清单脱敏投影、范围、摘要及冻结记录 |
| `GET /api/evaluations/{evaluation_id}/metrics/{metric}` | 分页回查指标分子、分母及记录贡献 |
| `GET /api/evaluations/{evaluation_id}/records/observations/{observation_id}` | 回查冻结原始观测 |
| `GET /api/evaluations/{evaluation_id}/export` | 下载含报告与清单投影的本地JSON文件 |

明细参数为`variant=primary/all_events/excluding_suspected`、`offset`和`limit`，默认每页50条，上限200条。报告接口由安全管理角色访问，并校验工作面权限；原有手工`POST /api/evaluations`冻结入口继续兼容。
