# 匿名展示副本

展示副本使用独立源码目录、前端构建和运行库。原有业务接口、模型及资料范围规则继续生效，模型环境和已核验权重复用本机配置。

## 展示名称

构建时设置`VITE_PRESENTATION_MODE=anonymous`，并通过`VITE_PRESENTATION_ALIASES`提供一一对应的名称映射。例如下列编号为配置示例：

```powershell
$env:VITE_PRESENTATION_MODE='anonymous'
$env:VITE_PRESENTATION_ALIASES='[["12345","A-01"],["某某煤矿","示范矿井"]]'
node node_modules/vite/bin/vite.js build --outDir <副本前端目录>
```

浏览器接收的来源、测点、模型编号、资料标题、正文、引用、字典键及错误消息统一转换为展示别名。后续业务请求还原为本机协议编号，使上下文校验、模型绑定和原文查询保持一致。测值、原始数值字符串、凭据和数据校验值不作为名称替换。

这是本机展示匿名：原始协议编号和映射保留在本机运行库及构建配置中。资料性质保持原值，真实资料继续留在本机，不因改名进入合成来源允许名单。

## 资料与报告下载

匿名页面的资料下载使用当前展示的标题、原文片段和页段生成TXT摘录。原始PDF、DOCX等二进制原件下载在展示客户端拦截。普通构建继续使用原件下载。

匿名评估导出使用`anonymous-display-v1`格式。原冻结报告与清单的摘要以`source_*`字段保留，匿名展示记录另计算`display_sha256`，避免将原摘要当作匿名内容的校验值。

## 页面文案

页面删除能力宣传副标、重复用途说明及“结构化模板”“适配器状态”等实现术语。助手根据实际任务显示“业务查询”“本机查询”或“DeepSeek”；工具步骤显示业务名称、状态、耗时及必要参数。历史回放、实验模型、资料有效期、数据质量、人工审核和失败缺项继续保留。

## 验证

单元测试覆盖编号往返、字典键、编码URL、凭据和测值保护、表单上传、原件拦截及匿名导出校验。界面回归覆盖实际处理通道、工具步骤和普通模式原件下载；展示副本另检查页面、原文和摘录中具体名称的残留。
